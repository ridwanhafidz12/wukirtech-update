Teknologi yang Digunakan Untuk mewujudkan platform DIGIRI, kami mengombinasikan empat pilar teknologi utama. Setiap teknologi dipilih secara strategis untuk menjawab masalah spesifik yang telah diidentifikasi (kesejahteraan yang rendah, akses pasar terbatas, dan digitalisasi yang 13 minim). Adapun beberapa teknologi yang digunakan dalam pengembangan platform ini sebagai berikut: a. Modern Web Application (Next.js & PWA) Fondasi platform DIGIRI dibangun menggunakan Next.js dan React, kerangka kerja web modern yang menjamin performa tinggi dan Search Engine Optimization (SEO) yang optimal. Kami menerapkan konsep Progressive Web App (PWA) yang memungkinkan pengguna mengakses platform langsung melalui peramban di ponsel atau laptop tanpa perlu mengunduh aplikasi berat dari App Store/Play Store. Teknologi ini memberikan pengalaman pengguna yang cepat, responsif, dan mampu menjangkau pasar global tanpa hambatan instalasi, mengatasi masalah minimnya literasi digital pada target audiens. b.  Invisible Blockchain & NFT  Kami menerapkan inovasi Web3 yang "tidak terlihat" (invisible blockchain) untuk mendukung konsep "Phygital" (Physical + Digital). Menggunakan Crossmint API, sistem kami secara otomatis mencetak (minting) Sertifikat Keaslian Digital (NFT) di jaringan Polygon saat transaksi terjadi. Keunggulan utamanya adalah mekanisme email-to-wallet: pembeli tidak perlu memiliki dompet kripto (wallet) atau memahami teknis blockchain. NFT dikirimkan langsung ke email pembeli yang terhubung dengan dompet custodial yang aman. Metadata NFT ini mencakup detail pengrajin, lokasi, dan filosofi motif, yang menjamin keaslian produk dan memungkinkan skema royalti abadi bagi pengrajin jika aset ini diperjualbelikan kembali di masa depan. c. Artificial Intelligence (AI) DIGIRI mengintegrasikan kecerdasan buatan terbaru Google Gemini 2.0 Flash melalui layanan @google/genai sebagai otak dari fitur "Asisten Cerdas Batik". Berbeda dengan chatbot konvensional, AI ini memiliki konteks mendalam mengenai data produk, sejarah, dan nilai filosofis setiap motif batik Giriloyo. d. Game Kami menggunakan gamifikasi sebagai hook utama untuk edukasi dan engagement. Kami mengembangkan dua game yaitu: 1) Mencanting Virtual. Ini adalah inti dari aspek imersif. Pengguna dapat mencoba pengalaman mencanting secara digital, memberikan edukasi budaya yang mendalam dengan cara yang interaktif dan menyenangkan. 14 2) Kuis Cerdas Berbatik (Model Quizizz/Wayground). Ini adalah game kompetitif (kuis real-time dengan leaderboard) tentang sejarah Batik Giriloyo dan budaya Yogyakarta. Tujuannya adalah untuk engagement berulang, promosi, dan edukasi yang terukur. 8. Implementasi Teknis Teknologi yang Digunakan Berikut adalah rincian technology stack yang kami usulkan untuk pengembangan prototipe selama kompetisi: • Web Frontend (PWA): o Framework: React (Next.js). Dipilih karena kemampuan Server-Side Rendering (SSR) dan Static Site Generation (SSG) yang krusial untuk SEO marketplace dan kecepatan loading halaman. o Styling: TailwindCSS. Dipilih untuk kecepatan pengembangan UI/UX yang sangat tinggi, penting untuk timeline yang ketat. o PWA: Dikonfigurasi menggunakan plugin next-pwa untuk fungsionalitas offline dan installable. • Backend & Serverless Architecture   o API Routes: Next.js API (Serverless Functions). Alih-alih membangun backend monolitik terpisah (seperti NestJS), kami mengintegrasikan logika backend langsung di dalam Next.js melalui folder pages/api. Ini menyederhanakan arsitektur, menghilangkan overhead manajemen server, dan mempercepat komunikasi data antara frontend dan backend. o Language: TypeScript. Digunakan secara menyeluruh (Fullstack) untuk menjamin keamanan tipe data (type-safety) dan mengurangi bug selama pengembangan. • Database & Real-time System o Primary Database: Google Firebase (Firestore). Kami menggantikan database SQL tradisional dengan NoSQL Firestore. Ini dipilih karena skalabilitas otomatis dan kemudahan integrasi untuk data produk, profil pengguna, dan transaksi. 15 o Real-time Features: Memanfaatkan kemampuan real-time listener bawaan Firebase untuk fitur Leaderboard Kuis dan status pesanan, menghilangkan kebutuhan akan konfigurasi WebSocket/Socket.io manual yang rumit. • Game 1: Mencanting Virtual o Engine/Library: Pixi.js. Ini adalah library rendering 2D (WebGL) berkinerja tinggi. Dipilih karena ringan, terintegrasi mulus di dalam komponen React, dan ideal untuk membuat simulasi drawing/painting (mencanting) yang responsif di browser. • Game 2: Kuis Cerdas Berbatik o Teknologi: Kombinasi React di frontend untuk UI, Socket.io di backend (NestJS) untuk komunikasi real-time, dan Redis untuk manajemen leaderboard. • Artificial Intelligence Integrasi: Langsung di dalam Backend (NestJS) o Engine: Google Gemini 2.0 Flash. Model terbaru yang lebih cepat dan efisien. o Integrasi: Menggunakan SDK official @google/genai yang dijalankan di sisi server (Next.js API). o Fungsi: Backend bertindak sebagai secure proxy yang menyimpan API Key, melakukan prompt engineering (Contextual Product Data), dan mengirimkan respons personalisasi kepada pengguna (Mode CS & Rekomendasi). •  Ekosistem Pendukung (Third-Party Services) o Payment Gateway: Midtrans. Terintegrasi penuh (Snap JS) untuk memproses pembayaran rupiah (QRIS, E-Wallet, VA) secara aman. o Email Service: Resend. Digunakan untuk mengirim notifikasi transaksional dan notifikasi NFT (sukses/gagal) dengan reliabilitas tinggi. • Blockchain & "Invisible" NFT (Phygital) o Minting Engine: Crossmint API. Kami tidak menulis Smart Contract manual (Solidity) untuk mempercepat proses. Sebaliknya, kami menggunakan Crossmint API yang secara otomatis mencetak NFT di jaringan Polygon (EVM-compatible Layer 2). 16 o Wallet Solution: Email-to-Wallet (Custodial). Ini adalah fitur kunci untuk adopsi massal. Sistem secara otomatis membuatkan dompet digital yang aman terhubung dengan email pengguna. Pembeli batik menerima NFT tanpa perlu install MetaMask atau mengerti crypto, mengatasi hambatan "digitalisasi rendah". o Metadata: Metadata NFT (Gambar, Atribut Pengrajin, Lokasi) disusun di backend dan dikirim ke Crossmint untuk disimpan secara permanen.
